# Лабораторна робота №4 — JavaScript, варіант 15

Виконавець: Остап Левинець.

## Частина 1: JavaScript

У папці `lab4` виконайте:

```powershell
py -m http.server 8044 --bind 127.0.0.1
```

Відкрийте http://localhost:8044 у браузері. Для зупинки сервера натисніть Ctrl+C. Потрібен HTTP-сервер, оскільки JavaScript підключено як модуль.

- `index.html` — резюме на основі лабораторної №3.
- `styles.css` — оформлення, світла й темна теми, модальне вікно.
- `script.js` — події, Fetch API, таймер, взаємодія з DOM.
- `config.js` — налаштування та спільні допоміжні функції.

## Частина 2: React

```powershell
cd lab_2_react
npm ci
npm run dev
```

Відкрийте адресу, яку виведе Vite. Перевірки: `npm run lint` і `npm run build`.

React-версію створено на основі проєкту лабораторної №2. `App.jsx` керує темою через useState/useEffect; `Reviews.jsx` завантажує й відображає відгуки; `ContactForm.jsx` керує формою й таймером; `Footer.jsx` зберігає та читає системні дані. Ефекти очищують таймери, слухачі й запити.

## Formspree

Endpoint `https://formspree.io/f/xrppypwd` підключено у `config.js` та `lab_2_react/src/config.js`. React production-версію перебудовано.

Форма надсилає дані POST-запитом до Formspree. Успішний статус показується лише після успішної відповіді сервісу. Для перевірки доставлення надішліть повідомлення зі сторінки та перевірте пошту, прив’язану до форми.

## Реалізовані вимоги

1. Доступна браузеру інформація про ОС, браузер, мови, екран та часовий пояс зберігається в localStorage як JSON. Додаткові дані User-Agent Client Hints збираються за наявності підтримки й дозволу браузера. У футері розкрийте «Системна інформація та localStorage»: там показані всі ключі та значення localStorage поточного походження. Дані, приховані браузером, отримати неможливо.
2. Реальний GET-запит до https://jsonplaceholder.typicode.com/posts/15/comments. Порядок відповіді збережено; відгуки вигадані. Передбачені завантаження, порожня відповідь, помилка та повторний запит.
3. Через 60000 мс після завантаження відкривається форма з ім’ям, email, телефоном і повідомленням. Є ручне відкриття, закриття кнопкою та Escape, браузерна валідація й повідомлення про результат. Автоматичний таймер одноразовий; після закриття не повторюється до перезавантаження сторінки. Ручне відкриття скасовує очікуване автоматичне відкриття.
4. Денна тема діє з 07:00 включно до 21:00 невключно, решта часу — нічна. Час береться з локальних налаштувань браузера. Автоматичний режим перевіряє час щосекунди. Ручний вибір діє до натискання «Тема за часом» або перезавантаження.

## Що перевірити під час демонстрації

- Відкрити футер і вкладку DevTools → Application → Local Storage.
- Показати 5 відгуків для допису №15; у Network знайти відповідний запит.
- Перемкнути тему вручну та повернути автоматичний режим.
- Дочекатися хвилини або відкрити форму кнопкою «Зв’язатися».
- Надіслати повідомлення через Formspree й показати лист.

Перевірено production-збірку React, ESLint, синтаксис JavaScript та роботу обох версій у headless Chrome: реальні відгуки, localStorage, теми, таймер 60 секунд (зі змодельованим часом), закриття/повторне ручне відкриття, відсутність горизонтального прокручування при ширині 390 px. Endpoint Formspree підключений; доставлення листа у поштову скриньку ще не перевірено.
